Lo script installa RustDesk, lo collega al nostro server, imposta una password permanente casuale e stampa ID e password: annotali e registra la postazione.

Script Windows (.ps1) Script Linux (.sh)

Windows: PowerShell come Amministratore, nella cartella del file: prima Unblock-File .\rd-win.ps1, poi powershell -ExecutionPolicy Bypass -File .\rd-win.ps1. Se la policy blocca ancora lo script, apri il file in Blocco note, copia tutto e incollalo nella finestra PowerShell. Linux: sudo bash rd-linux.sh (Debian/Ubuntu).

Modalità manuale

Se non puoi eseguire lo script: installa RustDesk dal sito scegliendo Installa, poi:

  1. ⋮ → Rete → sblocca → Server ID e Server relay: {{ id_server }}, Key: {{ public_key }} → Applica (in basso deve comparire “Pronto”).
  2. ⋮ → Sicurezza → sblocca → solo password permanente → imposta una password lunga e salvala nel password manager.
  3. Verifica che il servizio sia abilitato (serve per l’accesso con utente scollegato e dopo il riavvio).
  4. Copia l’ID e registra la postazione.

Server RustDesk non configurato: imposta RUSTDESK_ID_SERVER e RUSTDESK_PUBLIC_KEY nel .env (vedi deploy/rustdesk/README.md).
