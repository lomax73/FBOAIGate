# FBOAIGate

Gateway di accesso sicuro (senza port forward) verso un registro di host — NUC Debian con
Claude Code, e in futuro altri server (es. una VPS) — richiamabile da FBOPortal, da
qualunque luogo. Include anche un bot Telegram per l'invio comandi.

**Si riparte da qui: leggi `STATO.md` per primo.**

- `STATO.md` — punto di partenza per la prossima sessione: cosa è stato deciso e fatto,
  cosa manca, da dove ripartire.
- `fase_-1_workflow.md` — protocollo di esecuzione delle fasi.
- `fase_0..5_*.md` — fasi di sviluppo, in ordine.
- `fase_8_modifiche_rifinitura.md` — dubbi aperti e decisioni prese (file vivo).
- `design/` — identità visiva (icone SVG, `BRAND.md`).
- `docs/` — documentazione aggiuntiva (vuota per ora).
